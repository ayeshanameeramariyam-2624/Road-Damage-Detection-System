# AI Model - Road Damage Detection System

## Role
AI/ML Developer

## Objective
To develop a computer vision model that detects road damages such as potholes and cracks from road images.

## Technologies
- Python
- YOLO
- OpenCV
- Machine Learning
- Computer Vision

## AI/ML Tasks
1. Dataset preparation
2. Image preprocessing
3. Model training
4. Road damage detection
5. Model testing and evaluation
6. Severity estimation
